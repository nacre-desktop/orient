# Orient regression gallery

The six images and four-frame animation are original procedural test artwork,
created by generate.py for this project and dedicated to CC0-1.0. They are not
wallpapers copied from the user's library or commercial games. Keep the generator
and source attribution with the fixtures. They intentionally exercise warm shadows,
navy nights, bright neutral skies, subdued forest hues, neon minorities and gray.

palettes.json is a reviewed snapshot of every personality in dark/light mode
(hour18 for Tide). It stores roles and measured minimum contrast, not unstable
cache paths/fingerprints. Test code regenerates it to expose palette changes.
Run generate.py and snapshot.py explicitly when a deliberate engine change is
reviewed. Generated before/after render sheets stay outside the installed tree.
